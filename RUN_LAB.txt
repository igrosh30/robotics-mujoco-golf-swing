GOLF SWING - QUICK START

The lower body is anchored for this arm-motion demonstration. The shoulders
and elbows reproduce the bent trail arm and straighter lead arm in Figure 1.
The club accelerates through the ball and the ball launches through contact. Gravity, motor
torques and club/ball contact remain simulated; standing balance is not.

Watch the simulation:
  .\.venv\Scripts\python.exe main.py --slow-motion 3 --repeat

Create or update the front and side visuals:
  .\.venv\Scripts\python.exe export_visuals.py

Only four files are created in exports:
  front.gif - animated front view
  side.gif  - animated side view
  front.png - main swing poses from the front
  side.png  - main swing poses from the side

Each PNG is a ten-stage sheet, arranged in two rows like the lab-guide image, you can insert into your report or crop.
Re-running updates the same four files. No graphs, CSVs, JSON or PDF are generated.

The explanation of the model and equations is in UNDERSTAND_THE_PROJECT.txt.
The file starts with notes covering the professor's questions,
including DOF, constraints, quantified actuation and the limits of the current tests.
main.py controls the simulation; human.xml defines the physical model.
swing_trajectory.py contains timing, hand poses and club direction. Its poses
columns are torso degrees, hand X/Y/Z metres in upper_torso, and club phase degrees.
The reference solver coordinates the shoulders, elbows and wrist automatically.

Compare the baseline with a 3 N m, 8 Hz external wrist torque:
  python main.py --headless
  python main.py --headless --disturb-joint right_wrist_cock --disturb-amplitude 3

The previous tests/validate_swing.py is not present in this checkout.
This disturbance does not change friction or test foot slip.

Both models/golf_club.stl and models/golf_club_head.stl are required. The latter
is the small head collider and needs reviewing if the supplied mesh/transform changes.
The previous tools/build_club_collision.py is not present in this checkout.
.venv is the Python environment when created using the setup commands below.

On a new computer:
  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
